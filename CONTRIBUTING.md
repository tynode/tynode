# Contributing

Bug reports and ideas are the most useful thing right now. Please use the issue
templates and say what you were trying to trace, what you expected and what
happened. Remove prompts, keys and email addresses from anything you paste.

Code changes: open an issue first for anything larger than a small fix, then a
pull request against `main`. The engine lives in `apps/console`, the SDK in
`packages/sdk-python`. Run `tools/sync-sdk.ps1` after editing
`apps/console/static/tynode_sdk.py`.
